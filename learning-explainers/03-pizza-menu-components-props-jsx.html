03 Pizza Menu: Components, Props, JSX

Mục tiêu của bài này là đọc được bản final từ trên xuống dưới: React gắn app vào DOM, App dựng cây giao diện, Menu render danh sách pizza, Pizza nhận dữ liệu qua props, và Footer render khác nhau theo giờ mở cửa.

Starter so với final

Starter

Có dữ liệu pizzaData, CSS, và ảnh. Nó là nguyên liệu để bạn tự dựng app.

Final

Có project React hoàn chỉnh. Dữ liệu starter được đặt trong src/index.js, rồi được render bằng components.

Cây component

App
├─ Header
├─ Menu
│  └─ Pizza x 6
└─ Footer
   └─ Order, nếu nhà hàng đang mở

Đây là cách React tổ chức UI: chia màn hình thành các hàm nhỏ, rồi ghép chúng lại bằng JSX.

JSX

JSX trông giống HTML nhưng nằm trong JavaScript. Trong project này, <Header /> là component tự viết, còn <header> là thẻ HTML thật. 

function App() {
  return (
    <div className="container">
      <Header />
      <Menu />
      <Footer />
    </div>
  );
}
JSX phải return một root element. Ở đây root là <div className="container">.

Props

Menu lặp qua pizzaData và truyền từng object pizza xuống Pizza qua prop pizzaObj. 

{pizzas.map((pizza) => (
  <Pizza pizzaObj={pizza} key={pizza.name} />
))}

Bên trong Pizza, prop được destructure: 

function Pizza({ pizzaObj }) {
  return (
    <li className={`pizza ${pizzaObj.soldOut ? "sold-out" : ""}`}>
      <img src={pizzaObj.photoName} alt={pizzaObj.name} />
      <div>
        <h3>{pizzaObj.name}</h3>
        <p>{pizzaObj.ingredients}</p>
        <span>{pizzaObj.soldOut ? "SOLD OUT" : pizzaObj.price}</span>
      </div>
    </li>
  );
}

Bài tập nhỏ

  1. Thêm một pizza mới vào pizzaData trong bản final. Có thể dùng lại một ảnh cũ để tránh tìm asset mới.
  2. Đổi component Pizza để hiển thị giá dạng $12 thay vì 12.
  3. Thêm prop currency từ Menu xuống Pizza, rồi render {currency}{pizzaObj.price}.
  4. Tự kiểm tra: pizza sold out vẫn phải hiện SOLD OUT, không hiện giá.
