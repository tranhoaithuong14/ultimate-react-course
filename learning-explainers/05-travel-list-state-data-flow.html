Travel List: hiểu state, props, event và derived data qua một app nhỏ

Mục tiêu của bài này không phải thuộc lòng code. Mục tiêu là đọc được luồng dữ liệu: component nào giữ state, component nào chỉ nhận props, và event đi ngược lên bằng callback nào.

Đường đọc code

Hãy đọc project theo thứ tự này. Mỗi file trả lời một câu hỏi khác nhau, nên đừng bắt đầu từ CSS.

1. Entry point src/index.js

React gắn toàn bộ app vào DOM và render <App />.

2. State owner components/App.js

App giữ danh sách items vì nhiều component cần dùng hoặc sửa danh sách này.

3. Inputs and actions Form, PackingList, Item

Các component con nhận callback qua props để yêu cầu App thay đổi state.

4. Derived output Stats.js

Stats không giữ state riêng. Nó tính số liệu từ items mỗi lần render.

Bản đồ component

Cách đọc quan trọng nhất: state nên nằm ở component thấp nhất nhưng vẫn đủ cao để mọi component cần nó có thể dùng.

App.js

Giữ state chính: items

  • handleAddItems: thêm item mới.
  • handleDeleteItem: bỏ item theo id.
  • handleToggleItem: đổi packed của một item.
  • handleClearList: xóa toàn bộ danh sách sau khi confirm.
Form.js

Giữ state tạm thời

description và quantity chỉ phục vụ form, nên ở ngay trong Form.

PackingList.js

Giữ state hiển thị

sortBy chỉ ảnh hưởng cách hiển thị danh sách, không thay đổi danh sách gốc.

Item.js

Không giữ state

Nhận một item, rồi gọi onToggleItem(item.id) hoặc onDeleteItem(item.id).

Stats.js

Tính dữ liệu dẫn xuất

numItems, numPacked, percentage đều được tính từ items.

Bốn đoạn code đáng học kỹ

Đây là lõi tư duy của project. Nếu bạn hiểu bốn đoạn này, phần còn lại chủ yếu là JSX và styling. 

function handleAddItems(item) {
  setItems((items) => [...items, item]);
}
function handleDeleteItem(id) {
  setItems((items) =>
    items.filter((item) => item.id !== id)
  );
}
function handleToggleItem(id) {
  setItems((items) =>
    items.map((item) =>
      item.id === id
        ? { ...item, packed: !item.packed }
        : item
    )
  );
}
sortedItems = items
  .slice()
  .sort((a, b) =>
    a.description.localeCompare(b.description)
  );
Điểm chính: filter, map, spread [...items], object spread { ...item }, và slice().sort() đều tạo dữ liệu mới thay vì sửa trực tiếp state cũ.
