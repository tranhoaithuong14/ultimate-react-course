# Mission: Learn React Through Ultimate React Course

## Why
Learn React by reading, running, and modifying the course projects in this workspace, starting with `03-pizza-menu`. The practical goal is to become able to explain and change each project without treating the final code as a black box.

## Success looks like
- Read a small React project from its entry point to its leaf components.
- Explain JSX, components, props, list rendering, and conditional rendering using code from this repo.
- Make small feature changes in starter projects, then compare the result against final code.

## Constraints
- Use the local course repo as the main learning context.
- Prefer short, project-specific exercises over abstract React drills.

## Out of scope
- Advanced React state management, routing, backend integration, and Next.js until the earlier projects are understood.
